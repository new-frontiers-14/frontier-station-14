# Внешность скафандров оперативников UNEON

Визуальное обновление четырёх комплектов: обычный (`syndicate`), медик (`syndiemedic`), командир (`syndiecommander`) и элитный (`syndieelite`). Обновлены общие состояния костюмов и соответствующих шлемов, включая иконки, изображения в руках, выключенный и включённый свет, а также имеющиеся в источнике варианты для отдельных рас.

Источник: `dead-space-server/dead-space-14`, commit `b59db59845255979517a9d1060fd53d7d8e97511`:

## Совместимость

Сохранены все исходные состояния RSI Frontier. Если одинаковое имя состояния есть в Dead Space, используются его PNG и описание состояния; для остальных состояний оставлены оригинальные PNG и метаданные Frontier. Поэтому специальные варианты для гарпий/собак и дополнительные `combat`-состояния (где они присутствуют только в Frontier) сохраняют прежний внешний вид. Неиспользуемые в нашей сборке дополнительные состояния Dead Space не добавляются.

Человек и Аркана используют общие гуманоидные состояния. Рептилии и вульпканины получают новые расовые состояния там, где такие состояния предусмотрены в соответствующем RSI источника. Прототипы экипировки и код не изменяются: броня, скорость, защита от давления/температуры, фонари, цены и выдача предметов остаются по правилам Frontier. Обновление также затрагивает предметы, которые используют эти же RSI через наследование.

## Проверка в игре

1. Выдать четыре костюма и соответствующие шлемы через админ-меню.
2. Проверить иконки на земле, изображения в обеих руках и надетую экипировку с четырёх сторон.
3. Проверить включение/выключение фонаря и снятие/надевание встроенного шлема.
4. Проверить человека, Аркану и рептилию; проверить шлем вульпканина.
5. Проверить сохранённые варианты для гарпий/собак, если они используются.

Сборка C# для изменения PNG и метаданных не требуется; стандартные проверки RSI выполняются при создании PR. Для применения на сервере нужна публикация обновлённой сборки и штатное обновление UNEON.
