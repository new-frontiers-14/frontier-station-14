# VIP аплинк UNEON

Приложение устанавливается во все ПДА при создании (дополнительное место под программу зарезервировано автоматически). Клиент показывает его в «Приложениях» только при действующей подписке. Сервер проверяет аккаунт покупателя заново при каждой покупке; ID-карта и владелец ПДА не определяют доступ или плательщика.

Оплата: банковский счёт персонажа через штатный `BankSystem`. Один запрос покупает один товар. Предмет появляется в свободной руке, а при занятых руках остаётся рядом с персонажем. Ограничение: одна покупка в секунду на персонажа. Подписка использует существующий ограниченный кэш; при подтверждённом снятии роли права исчезают при следующей проверке подписки, при недоступности API — по истечении grace period.

## Каталог

`Resources/Prototypes/_UNEON/VipUplink/catalogue.yml` содержит расширяемые товары. Начальные цены: сталь ×30 — 3000, стекло ×30 — 5000, пластик ×30 — 5000 кредитов. Это начальные цены для проверки, их можно менять независимо от кода.

- `id`: уникальный ID предложения.
- `name`: ключ локализации названия в ru-RU и en-US.
- `product`: ID прототипа выдаваемого предмета. Полные SheetSteel/SheetGlass/SheetPlastic содержат по 30 единиц.
- `price`: положительная цена в банковских кредитах.
- `minimumTier`: минимальный уровень подписки (по умолчанию 1).
- `allowedAccounts`: список UUID аккаунтов SS14, НЕ имён персонажей и НЕ Discord ID. Пустой список означает общий товар.

## Персональные скафандры (следующий этап)

Каждый скафандр добавляется через GitHub как отдельный прототип со спрайтами и локализацией. Для него добавляется предложение с `minimumTier: 4` и `allowedAccounts` с единственным UUID владельца. Владельцу доступны уровни 4 и 5; после снижения до 3 покупка и отображение исчезают. Другой подписчик даже уровня 5 не получает этот товар в ответе каталога и не может купить его, подделав ID запроса.

Пример шаблона (не добавлять в активный каталог до создания реального прототипа и подстановки UUID):

```yaml
- type: vipUplinkProduct
  id: UneonVipPersonalSuitExample
  name: uneon-vip-personal-suit-example
  product: REPLACE_WITH_EXISTING_SUIT_PROTOTYPE
  price: 50000
  minimumTier: 4
  allowedAccounts:
  - "REPLACE_WITH_OWNER_SS14_ACCOUNT_UUID"
```

Это ограничение покупки и отображения в магазине. Запрет носить/передавать уже приобретённый скафандр здесь не реализован.

## Проверка в игре перед публикацией

1. Без подписки приложение не видно в списке программ.
2. С уровнями 1 и 5 приложение доступно, показаны три материала и текущий банковский баланс.
3. Покупка списывает ровно цену товара и выдаёт ровно один стак ×30.
4. При обеих занятых руках стак оказывается рядом с покупателем.
5. При недостаточном балансе деньги не списываются и предмет не появляется.
6. Передача ПДА другому игроку меняет доступ и плательщика согласно аккаунту текущего пользователя. Одновременно открывшие ПДА пользователи не получают чужой баланс/персональные предложения: ответы направляются каждому отдельно.
7. После снятия роли и обновления подписки дальнейшие покупки запрещены.
8. Для персонального скафандра проверить владельца на уровнях 3/4/5 и другого игрока на уровне 5.

Покупки и ошибки создания предметов пишутся в журнал игрового сервера. Для применения кода/каталога нужна новая сборка и перезапуск игры. Обновлять VPS-бота для этого приложения не требуется.
